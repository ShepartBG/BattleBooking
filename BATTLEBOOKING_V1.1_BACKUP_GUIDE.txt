BattleBooking v1.1 Backup Guide

Before every bigger update:
1. Supabase -> Project -> Backups/Database -> create/download backup if available.
2. Supabase -> Table Editor -> export important tables if needed: organizers, fields, games, registrations, field_requests.
3. Keep the previous ZIP and the new ZIP in separate folders.
4. Deploy only after SQL is executed successfully and local build passes.

Important:
- Do not share SUPABASE_SERVICE_ROLE_KEY publicly.
- Keep .env.local out of GitHub.
- If something breaks after deploy, revert to the previous GitHub commit/Vercel deployment.
